Automated Auditing of Nucleus Class Annotations

Which annotations deserve a second look?

A reproducible, group-safe framework that ranks each potentially inconsistent annotation and recommends the highest-priority cases for expert review without rewriting the source labels.

Research prototype by Natan SmogórReleased 18 August 2026
Source annotations stay fixed → review evidence is ranked
Conceptual workflow · not benchmark data

Annotation auditing is a way to decide what a human should inspect first. It is not a way to replace the human decision.

Large histopathology datasets contain many already segmented nucleus instances, each paired with a class label. Even careful annotation can include ambiguity, inconsistent conventions or ordinary data-entry noise. Reviewing every instance again is expensive, so the useful question is not “can a model declare a label wrong?” It is “can a model create a better review queue than random sampling?”

AANCA evaluates that question under controlled conditions. It intentionally changes a known subset of class labels, hides that intervention from the auditor, and then measures whether the changed labels move toward the front of a fixed review queue. Because the benchmark records exactly what it changed, retrieval can be scored without pretending that model disagreement is biological truth.

The pre-corruption label is an experimental reference label, not guaranteed biological truth. It is used only to define the controlled benchmark, simulated restoration and final evaluation. In a real audit, a high score means recommended for expert review. It never means “confirmed error.”

Study boundary. This presentation reports the completed primary frozen-feature benchmark. Confirmatory CNN experiments, blinded expert review and external validation have not been performed. Model-selection rules were frozen before outcome interpretation; the accepted analysis remains exploratory because outcomes were subsequently exposed during technical recovery.

Research question

Can source-group-safe out-of-fold models retrieve controlled label inconsistencies more efficiently than random review, and does restoring the highest-ranked injected corruptions improve downstream nucleus classification?

How the benchmark works

One controlled question, unfolded step by step.

Each stage adds evidence while preserving the source record. Scroll to build the complete benchmark; the graphic remains fully visible on mobile and in reduced-motion mode.

  1. Reference

    Keep label states immutable and separate

    Each nucleus retains its source patch, experimental reference class and observed class.

  2. Intervention

    Inject a change the benchmark can verify

    Four frozen mechanisms create objective positives without changing the raw source files.

  3. Prediction

    Score only with unseen source groups

    No model may train on the scored nucleus or any other nucleus from its source patch.

  4. Triage

    Rank suspicion under an equal budget

    Guided and random review inspect the same number of cases; only their ordering differs.

  5. Evaluation

    Measure retrieval, then defer the decision

    Average precision and fixed-budget metrics score the queue. An expert still decides what a case means.

How to read the evidence

Four quantities answer four different questions.

Separating them prevents a strong ranking result from being mistaken for clinical or downstream utility.

01

Average precision

Asks whether injected label changes appear early across the entire ranked list. Higher is better; at 0% corruption it is not applicable.

02

Recall at 5%

Asks how many injected changes are found when an expert can review only the first 5% of the queue.

03

Random-review baseline

Uses the identical integer budget over 100 deterministic repetitions, making the operational comparison fair.

04

Restoration utility

Asks a separate downstream question: after simulated review, does restoring found injected changes improve final-fold macro-F1?

Primary downstream test · H4

Better triage did not improve the downstream model.

This is the most important negative result. Ranking injected inconsistencies and improving a later classifier are related, but they are not equivalent objectives.

The H4 experiment restored exactly the same 5% review budget under audit-guided and random selection, then trained the same downstream model and evaluated it on the untouched final reference fold. Audit-guided restoration was not favoured.

H2 · descriptive heterogeneity

Saved performance estimates varied across contexts.

The saved subgroup estimates span nucleus classes, tissues, corruption mechanisms and corruption rates. They describe where performance differed in this benchmark; they do not establish a causal biological dependency.

Subgroup average precision is reported only when the preregistered support rule is met: at least 100 samples and at least 10 injected corruptions. Otherwise the study retains counts without inventing an unstable estimate.

Group-safe splitting

Every split uses group_id, at least at source-patch level, never individual nuclei.

Out-of-fold ranking

Primary model-based audit scores come from predictions made for source groups excluded from model fitting.

Untouched final reference

The final reference fold is uncorrupted and unavailable for model selection, calibration or review-budget tuning.

Separate label states

pre_corruption_label, observed_label, is_injected_corruption and corruption metadata remain distinct.

Interpretation boundary

What this benchmark supports, and what it does not.

A technically strong audit can still be limited in scope. The boundary below is part of the result, not a disclaimer added afterward.

Supported by the controlled benchmark

  • Registered group-safe rankings retrieved injected class-label changes more efficiently than random review in H1.
  • The preregistered fixed hybrid exceeded self-confidence in all 12 H5 comparisons.
  • Every displayed number remains traceable to sealed machine-readable evidence.

Not established by this study

  • That a naturally occurring annotation is wrong or that a pathologist made an error.
  • That better ranking automatically improves downstream classification; H4 was adverse.
  • Patient/WSI independence, clinical validity, expert agreement or external generalisation.
