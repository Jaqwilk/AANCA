Automated Auditing of Nucleus Class Annotations

Which annotations deserve a second look?

A reproducible, group-safe framework that ranks each potentially inconsistent annotation and recommends the highest-priority cases for expert review without rewriting the source labels.

Research prototype by Natan SmogórUpdated 20 August 2026

Annotation auditing is a way to decide what a human should inspect first. It is not a way to replace the human decision.

Large histopathology datasets contain many already segmented nucleus instances, each paired with a class label. Even careful annotation can include ambiguity, inconsistent conventions or ordinary data-entry noise. Reviewing every instance again is expensive, so the useful question is not “can a model declare a label wrong?” It is “can a model create a better review queue than random sampling?”

AANCA evaluates that question under controlled conditions. It intentionally changes a known subset of class labels, hides that intervention from the auditor, and then measures whether the changed labels move toward the front of a fixed review queue. Because the benchmark records exactly what it changed, retrieval can be scored without pretending that model disagreement is biological truth.

The pre-corruption label is an experimental reference label, not guaranteed biological truth. It is used only to define the controlled benchmark, simulated restoration and final evaluation. In a real audit, a high score means recommended for expert review. It never means “confirmed error.”

Study boundary. This presentation reports the completed primary frozen-feature benchmark, the frozen NuCLS multi-rater evaluation and a separately frozen MoNuSAC controlled-external test on new images. NuCLS did not meet its ranking or downstream rules. MoNuSAC passed only the injected-change retrieval gate, not its downstream or class-safety gates. Confirmatory CNN experiments and newly recruited blinded expert review have not been performed. The accepted PanNuke analysis remains exploratory because outcomes were exposed during technical recovery.

Method

A controlled audit begins by preserving what the model is allowed to know.

The benchmark does not ask a classifier to overwrite a pathologist's annotation. It creates a controlled setting in which a known subset of labels is changed intentionally, while the source record, reference label and corruption metadata remain separate and immutable.

All development splits are made by group_id, at least at source-patch level. A nucleus can be scored only by a model that was trained without that nucleus and without every other nucleus from the same source patch. This produces one group-safe out-of-fold probability vector for every audited instance.

Those probabilities are converted into review-priority scores. The primary self-confidence score asks how little probability the model assigns to the observed label; complementary methods add likelihood, margin, ambiguity and fold-safe neighbourhood evidence. Higher scores mean earlier review, never automatic correction.

Finally, guided and random review receive the same integer budget. The benchmark measures whether injected changes appear earlier in the guided queue and then asks a separate question: whether restoring only the reviewed injected changes improves a downstream classifier on the untouched final reference fold.

One controlled question, unfolded step by step.

The diagram shows the complete governed path: preserve the reference, create a known intervention, predict without source-patch leakage, rank an equal review budget and measure retrieval while leaving the final decision to an expert.

Four quantities answer four different questions.

Separating them prevents a strong ranking result from being mistaken for clinical or downstream utility.

Average precision describes the complete ordering of the review queue. Recall at the primary 5% budget describes the operational slice an expert would actually inspect. The random-review baseline tells us whether that prioritisation is better than spending the same review effort without a model.

Restoration utility is deliberately separate. It asks what happens after simulated review when found injected changes are restored and the downstream classifier is retrained. A ranking can retrieve controlled inconsistencies efficiently while still failing to improve the later classifier.

Intervals and adjusted tests also answer different questions. The displayed 95% intervals come from paired whole-group bootstrap resampling; registered Holm-adjusted values are one-sided. At 0% corruption, average precision is not applicable because the controlled positive event does not exist.

Better triage did not improve the downstream model.

This is the most important negative result. Ranking injected inconsistencies and improving a later classifier are related, but they are not equivalent objectives.

The external test did not establish natural-disagreement ranking or downstream benefit.

A genuine multi-rater evaluation was completed on NuCLS. Completion records that the frozen study ran; it does not turn a null or adverse result into a success.

The protocol was committed and publicly tagged before the NuCLS outcome tables were downloaded. The primary Unbiased Control subset paired the official inferred non-pathologist label with independently inferred pathologist consensus by exact anchor_id. It retained 811 nuclei from five TCGA patients, held each patient out as a complete group and found 27 natural NP/P disagreements. Consensus is an external reference signal, not guaranteed biological truth.

Average precision was 0.073489 against disagreement prevalence 0.033292. The AP-minus-prevalence interval was above zero, but the frozen operational condition was not: at the 5% budget, 4 of 41 reviewed nuclei disagreed and the precision-minus-prevalence 95% interval was [-0.030075, 0.154075]. Because both conditions were required, the ranking claim was not supported.

The retrospective correction test was also negative. Guided review produced macro-F1 0.749335, compared with 0.761085 for mean random review and 0.763969 with labels left unchanged. Guided minus uncorrected was -0.014633, with 95% interval [-0.026683, -0.002415]. The secondary Evaluation subset also failed both frozen success rules and cannot rescue the primary result.

Therefore AANCA has now been tested on genuine external multi-rater evidence, but it has not been shown to detect true pathology errors or improve a model in real use. The honest result is narrower: this frozen method did not provide sufficient evidence for prioritising NuCLS NP/P disagreements and was adverse against leaving labels unchanged in the primary downstream comparison.

Independent readback. The public NuCLS evidence release includes a verifier that checks fixed SHA-256 identities and recalculates every ranking, random baseline, downstream metric and group bootstrap without importing AANCA's analysis code. Its primary conclusion is not_supported.

On new MoNuSAC images, AANCA improved controlled-change triage but did not establish safer retraining.

This protocol was frozen before metric execution. It tests artificial label changes on a new dataset, not naturally occurring pathology errors.

The official MoNuSAC training release supplied development data and its official test release remained untouched until final evaluation. Complete TCGA patients defined every group. Two patient identities found in both official archives were removed from development only, leaving 29,610 eligible development nuclei from 44 patients and 15,494 final-test nuclei from 25 patients. Exactly 2,961 development labels were changed under the frozen 10% symmetric mechanism; source annotations themselves were never edited.

At the fixed 5% budget, the primary balanced neighbour queue reviewed 1,481 nuclei and found 1,035 injected changes. Its precision was 0.698852. The gain over 20 exact class, organ and proposed-transition matched-random queues was +0.142843, with a 95% whole-patient interval of [+0.099181, +0.188491]. This registered retrieval condition passed.

The downstream result was more cautious. Training after primary review produced macro-F1 0.509361 on the untouched test patients, compared with 0.503835 when corrupted labels were left unchanged. The difference was +0.005526, but its interval [-0.001506, +0.012833] crossed zero. Against mean exact-matched-random restoration the difference was +0.000031, with interval [-0.008692, +0.008486]. The important-class recall safeguard also failed.

The result is a real improvement in controlled-change prioritisation on external images, but not proof of downstream benefit. Only one of four simultaneously required success conditions passed, so every executable adoption guard retained the uncorrected comparison. The fixed hybrid had the best ranking point estimate, but it was not the frozen primary and was not promoted after seeing the final result.

Independent readback. The checked-in MoNuSAC result is bound to a 9.9 MB numeric package. A verifier that imports only the standard library and NumPy recalculates all four rankings, exact matched controls, downstream metrics and 2,000-draw whole-patient bootstrap gates. The full frozen experiment was run twice with identical scientific results.

The source masks remained untouched.

The validator measured cross-class overlaps and unlabeled regions, retained them in provenance and applied one frozen eligibility policy. It never arbitrated an overlap class or reconstructed the supplied background.

Before any primary split is frozen, the inspector verifies folds, shapes, channels, class order, instance identifiers and representative overlays. Cross-class overlaps, void pixels and affected instances are recorded rather than silently corrected.

The overlay is evidence about ingestion and representation, not improved segmentation. Eligibility flags may follow the frozen policy, but the raw masks and source annotations remain unchanged.

The design limits outcome-informed model selection.

The model, split, feature and statistical rules were frozen before outcome interpretation. Because outcomes were later exposed during recovery, this accepted result is reported as exploratory rather than as an untouched confirmatory analysis.

Source groups stay together, each audit score is out of fold, the final reference fold is withheld from selection, and every label state remains separate. The matrix retained all 36 comparison entries; unavailable optional pathology cells were not replaced with estimates.

Outcome exposure during technical recovery does not change the stored measurements, but it narrows what can responsibly be claimed. The accepted primary analysis is therefore permanently described as amended and exploratory.

What the evidence supports, and what it does not.

A technically strong audit can still be limited in scope. The boundary below is part of the result, not a disclaimer added afterward.

The controlled positive event is an injected label change. Performance against it measures retrieval of that injected process, not naturally occurring annotation inconsistency, expert disagreement or biological truth. A bootstrap quantifies uncertainty within one dataset; it does not create an independent replication.

PanNuke splits separate source patches, not verified patients or whole slides. Its controlled allocation also used the pre-corruption reference label for balance. That label was not a model input, but it is benchmark-only information unavailable in a real audit.

The NuCLS study used genuine external multi-rater evidence, a protocol frozen before outcome download and complete TCGA-patient grouping. Its null/adverse result narrows the evidence. The separately frozen MoNuSAC test adds many new images and patient groups, but its positive result concerns injected changes and its downstream gates failed. Neither study establishes natural-error detection or operational utility. Those claims still require newly recruited blinded experts, prospective use across sites and outcomes defined before deployment.

Supported by the controlled benchmark

  • Registered group-safe rankings retrieved injected class-label changes more efficiently than random review in PanNuke H1.
  • The frozen MoNuSAC primary queue also beat exact matched random for injected-change retrieval on new images.
  • Every displayed number remains traceable to sealed machine-readable evidence.

Not established by this study

  • That a naturally occurring annotation is wrong or that a pathologist made an error.
  • That guided correction safely improves downstream classification; PanNuke H4 and NuCLS were adverse, while MoNuSAC remained uncertain and failed class safety.
  • Clinical validity, prospective utility or broad real-world generalisation.
