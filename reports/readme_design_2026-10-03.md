## Implemented hierarchy

The header uses AANCA's canonical four-tile mark, full project name, short descriptor,
seven navigation routes and truthful badges for actual CI, reference Python,
non-clinical use and limited evaluation permission. GitHub owns the type system and
light/dark themes; the README introduces no custom styling or JavaScript.

Browser review and software quick start now precede the long result table. Three
review routes use a compact list that wraps on a phone. Negative PanNuke,
NuCLS multi-rater and MoNuSAC outcomes, PUMA's controlled-data/chronology limitations
and `retain_uncorrected` remain visible. Ten native disclosures retain exact result
comparisons, calibration/candidate qualifications, reproduction levels, repository
boundary, stages, specialist documents and complete validation commands.

All 42 original numeric code literals, seven original code blocks and 39 original
Markdown link targets are retained. Legacy installation and reproduction anchors
remain addressable. The licence, source-data terms, no-DOI statement and
AI-assistance/responsibility disclosure remain intact.

The mark is included in fresh 68-file offline kit candidates, so the relative README
image is present after extraction. The already published 67-file `reviewer-kit-v1`
archive, tag and pinned download identity remain immutable.
